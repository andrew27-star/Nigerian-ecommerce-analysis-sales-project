# Nigerian E-Commerce Data Analysis Project

## 📊 Overview
This project is a simple data analysis of a simulated Nigerian e-commerce dataset.  
It explores sales performance, revenue generation, and product/category trends using Python.

---

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Git & GitHub

---

## 📂 Dataset
The dataset contains 1000 simulated e-commerce orders with the following fields:
- OrderID
- Product
- Category
- Price
- Quantity
- State
- OrderDate
- Revenue (calculated)

---

## 📈 Key Insights
- Total revenue was calculated using Price × Quantity
- Top-performing products were identified
- Revenue by state and category was analyzed
- Visualizations were created using Matplotlib
