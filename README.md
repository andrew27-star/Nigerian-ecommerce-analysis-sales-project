# Nigerian E-Commerce Sales Analysis

## Overview

This project analyzes a simulated Nigerian e-commerce dataset containing 1,000 customer orders. The objective is to identify sales trends, top-performing products, customer purchasing behavior, and regional revenue performance using Python.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib

## Project Features

* Generated and analyzed 1,000 e-commerce transactions
* Calculated key performance indicators (KPIs)
* Performed product-level sales analysis
* Evaluated revenue performance across Nigerian states
* Identified top customers by revenue contribution
* Analyzed monthly revenue trends
* Created visualizations for business reporting

## Key KPIs

* Total Revenue
* Total Orders
* Products Sold
* Average Order Value

## Visualizations

The project includes:

* Revenue by Product
* Revenue by State
* Monthly Revenue Trend
* Revenue Distribution by Category

## Business Insights

* Identified the highest revenue-generating product
* Identified the highest revenue-generating state
* Ranked top customers by total spending
* Compared category performance and sales contribution
